## 前言：这是一款什么样的工具？

**Image Canvas Stitcher（图片自由拼接工具）** 是一款完全免费、开源、跨平台的桌面应用程序。它像一个“无限大的数字画布”，您可以把多张图片像贴纸一样随意拖放到画布上，自由调整它们的位置、大小、层次和透明度，最后将它们合并成一张完整的大图导出。

**任何人都能用它做什么？**

-   **普通用户/学生**：制作学习笔记拼图、旅行照片合集、表情包组合、作业素材排版。
-   **设计师/创意工作者**：快速制作情绪板（Mood Board）、设计稿对比、素材收集与整理、界面原型拼接。
-   **产品经理/运营**：制作产品功能截图对比、竞品分析报告、社交媒体长图。
-   **程序员/测试人员**：并排对比代码截图、UI 测试结果可视化、Bug 截图标注。
-   **教师/培训师**：制作教学课件素材、知识点视觉化拼图。

**它的核心哲学是：自由、直观、不限制创意。**

## 第一部分：零基础入门指南（5分钟学会）

如果您是第一次接触这款软件，请按以下步骤操作，5 分钟就能上手。

### 1. 安装与启动

-   **下载**：请从官方 GitHub 仓库的 Releases 页面下载适合您操作系统的可执行文件（.exe, .app 或 .run）。
-   **安装**：解压下载的压缩包，双击运行 `Image_Canvas_Stitcher.exe`（Windows）或对应程序。
-   **启动**：程序启动后，您会看到一个深灰色的主窗口，中央是一片广阔的深色画布。

### 2. 认识主界面

主界面非常简洁，主要分为三个区域：

-   **顶部工具栏**：一行整齐的按钮，包含所有核心操作，如导入、粘贴、缩放、调整透明度、导出等。
-   **中央画布区**：这是您工作的主要区域，所有图片都摆放在这里。您可以无限拖动、缩放视角。
-   **底部状态栏**：显示当前的操作提示、图片信息以及视图缩放比例。

### 3. 将图片放入画布（三种方法）

1.  **方法一：从剪贴板粘贴（最常用）**
    -   在浏览器或其他软件中**复制一张图片**（Ctrl+C 或右键复制）。
    -   回到本软件，按键盘上的 **Ctrl+V** 或点击工具栏的“粘贴”按钮。
    -   图片就会出现在画布中央。

2.  **方法二：拖拽文件**
    -   打开您的文件管理器（如“我的电脑”或“访达”）。
    -   选中一张或多张图片文件，直接用鼠标**拖拽**到软件窗口的画布上，松开鼠标即可。

3.  **方法三：使用“导入图片”按钮**
    -   点击工具栏的 **“导入图片”** 按钮。
    -   在弹出的文件选择窗口中，选中您要的图片，点击“打开”。

### 4. 调整图片的位置和大小

-   **移动位置**：用鼠标左键按住任意一张图片，拖动它，即可自由摆放。松开鼠标即固定位置。
-   **缩放图片（重要！两种模式）**：
    -   **模式一（缩放单张图片）**：先用鼠标**单击选中**一张图片（它会显示一个蓝色边框），然后**滚动鼠标滚轮**，这张图片就会以鼠标指针为中心放大或缩小。
    -   **模式二（缩放整个视野）**：如果**没有选中任何图片**（点击画布空白处取消选中），滚动滚轮可以拉近拉远整个画布的视野，方便您查看整体布局或细节。

### 5. 删除图片

-   单击选中要删除的图片，按键盘上的 **Delete** 或 **Backspace** 键。
-   或者，在图片上**单击鼠标右键**，在弹出菜单中选择 **“删除”**。

### 6. 导出你的作品

-   调整好所有图片的位置和大小后，点击工具栏的 **“导出大图”** 按钮。
-   选择保存位置，输入文件名，点击“保存”。
-   工具会自动计算所有图片的边缘，生成一张裁剪干净、背景透明的拼接大图。

这部分内容面向希望发挥该工具全部潜力的进阶用户，包含许多独特而强大的工作流。

### 1. 图片差异比对（设计师与测试人员的利器）

这是一个非常有特色的功能，可以自动高亮显示两张相似图片之间的不同之处。

-   **使用场景**：
    -   **设计评审**：并排放置新旧两版设计稿，一键标出改动区域。
    -   **UI 测试**：对比预期界面与测试截图，快速定位布局错误或像素偏移。
    -   **图像处理**：对比原图与修图后的效果，检查修改是否到位。
-   **操作方法**：
    1.  按住 **Ctrl 键**，用鼠标点击选中您想比对的两张（或多张）图片。
    2.  点击工具栏的 **“比对差异”** 按钮。
    3.  程序会自动分析图片，并在所有差异区域生成 **红色半透明标记框**。
-   **专业提示**：
    -   比对以您选中的**第一张图为基准**，将其余图片缩放至与基准图相同尺寸后进行像素级比对。
    -   如果两张图片尺寸不同，程序会自动拉伸（保持比例）其中一张以匹配基准图。这可能导致误报，因此建议先统一图片大小。
    -   点击 **“清除标记”** 按钮可移除所有红色标记。

### 2. 历史记录管理（安全的版本控制）

您可以将当前画布上的所有图片布局保存为一个“历史项目”，随时可以恢复。

-   **使用场景**：
    -   您正在制作一个复杂的长图，担心后续步骤无法撤回，可以先保存为历史记录。
    -   您希望尝试多种排版方案，每种方案都保存为一个历史版本，方便对比和回溯。
    -   您今天没做完的工作，保存后明天可以一键恢复，继续编辑。
-   **操作方法**：
    1.  **保存**：点击工具栏的 **“保存到历史”** 按钮，当前画布内容（所有图片、位置、大小、透明度）都会被完整保存。
    2.  **恢复**：点击 **“历史记录”** 按钮，打开历史列表。
    3.  在列表中，左侧是历史项目列表，右侧会显示**缩略图预览**和基本信息（时间、图片数量）。
    4.  选中一个项目，点击 **“加载编辑”**，即可将画布完全恢复到当时的模样。
-   **专业提示**：历史记录保存在您电脑的用户目录下（如 `C:\Users\你的用户名\.image_stitcher\history`），您也可以手动备份该文件夹。

### 3. 自动保存与崩溃恢复

程序会智能地在您每次操作（如移动、缩放图片）后，自动将状态保存在后台。如果程序意外关闭或电脑死机，重新启动后会自动询问并恢复您上次的工作进度。

-   **专业提示**：自动保存文件位于 `C:\Users\你的用户名\.image_stitcher\autosave`。您无需手动管理，程序会在下次启动时自动检测并恢复。

### 4. 导出透明背景大图

-   导出时，默认格式为 PNG，支持透明背景。这意味着您拼接好的图片可以作为素材，导入到 Photoshop、PPT 或其他设计软件中继续编辑，而不会带有任何背景色块。
-   如果您选择导出为 JPEG 格式，程序会自动将背景填充为白色，这是为那些不支持透明背景的场景准备的。

### 5. 高效交互模式

-   **空格键 + 鼠标拖拽**：专家级用户的“平移”标准操作，就像在 Photoshop 中一样流畅。
-   **鼠标滚轮**：集成了“选中缩放”和“视图缩放”两种功能，通过是否选中图片来智能切换，极大地提高了工作效率。
-   **右键菜单**：几乎所有功能都可以在图片上右键呼出，无需上移鼠标到工具栏，操作路径更短。

## 第四部分：技术说明与专业调参（开发与高阶用户）

### 核心引擎与框架

-   本工具基于 **Python** 和 **PySide6**（Qt for Python）框架开发。PySide6 是 Qt（一个世界顶级的跨平台 C++ 图形用户界面库）的官方 Python 绑定，这保证了程序在 Windows、macOS 和 Linux 系统上都能拥有原生般的性能和外观。
-   图形渲染使用了 Qt 的 **QGraphicsView/QGraphicsScene** 体系，这是一个高性能的 2D 图形框架，支持数千个图形项的流畅交互，非常适合处理大量图片的拖拽、缩放和渲染。

### 底层工作机制

1.  **无损缩放**：图片缩放时，程序并非简单地拉伸显示，而是根据当前的缩放因子，对原始图片（`_original_pixmap`）进行**重新采样（Resampling）** 和**平滑缩放（SmoothTransformation）**。这确保了图片即使被放大数倍，边缘依然清晰，避免了传统“越放越糊”的问题。
2.  **状态序列化**：所有图片的状态（位置、缩放、透明度、Z轴顺序等）在保存时会被序列化为一个轻量级的 **JSON 文件**。图片本身则被编码为 PNG 文件存储在本地。这种设计使得项目文件结构清晰，易于调试和备份。
3.  **像素级差异比对算法**：该功能采用**分块检测（Block-based Detection）** 和**连通区域分析（Connected Component Analysis）**。
    -   **分块检测**：将图片划分为 8x8 像素的小块，计算每个小块内所有像素的 RGB 颜色差值总和。只有超过阈值（默认为 30）的块才被视为“差异块”。这比逐像素比较更高效，且能过滤掉噪点。
    -   **连通区域分析**：通过广度优先搜索（BFS）将相邻的差异块合并成更大的矩形区域。这使得差异标记不再是散落的点阵，而是聚合为有意义的、可读性强的“区域”，让您一目了然地看到变化的范围。

### 性能调优参数（高级）

对于开发者或希望极致性能的用户，您可以在代码开头的“配置常量”区域调整以下参数：

-   `AUTOSAVE_DELAY_MS = 1500`：自动保存防抖延迟（毫秒）。数值越大，保存频率越低，但在复杂场景下可减少 I/O 开销。
-   `MAX_HISTORY_ITEMS = 50`：最大历史记录数量。超过此数量会自动清理最早的记录，防止硬盘空间被占满。
-   `block_size = 8`：差异比对算法的分块大小。增大此数值（如 16）可提高检测速度，但会降低差异区域的精确度；减小数值（如 4）则精度更高，但速度会变慢。
-   `threshold = 30`：颜色差异阈值。数值越小，对颜色变化越敏感，越容易标记出差异；数值越大，则只标记出差别很大的区域。

## V1.0 — Tkinter 原型版（奠基之作）

### 文件信息
- **文件名**：`Image_Canvas_Stitcher - 1.0 thk.py`
- **框架**：Tkinter + PIL (Pillow)
- **依赖**：可选 `tkinterdnd2`（拖放支持）、可选 `win32clipboard`（增强粘贴）

### 核心功能
这是工具的**第一个可用版本**，采用 Python 标准库 Tkinter 构建，验证了图片自由拼接的核心交互模型。

#### 功能清单
1. **图片导入**
   - 通过 `filedialog` 选择图片文件
   - 支持的格式：PNG、JPG、JPEG、BMP、GIF、WEBP、TIFF

2. **剪贴板粘贴**
   - `Ctrl+V` 从系统剪贴板粘贴图片
   - 使用 `PIL.ImageGrab.grabclipboard()` 获取剪贴板图像
   - Windows 下支持通过 `win32clipboard` 读取 CF_DIB 格式

3. **拖拽文件导入**（可选）
   - 通过 `tkinterdnd2` 库支持文件拖拽
   - 文件拖入画布时自动加载

4. **图片操作**
   - 鼠标左键拖动移动位置
   - 滚轮缩放选中的图片（以鼠标为锚点）
   - 选中状态显示蓝色边框

5. **图层管理**
   - 置顶（Bring to Front）：将选中图片移到最上层
   - 置底（Send to Back）：将选中图片移到最下层

6. **画布平移**
   - 按住空格键 + 鼠标左键拖动
   - 鼠标中键直接拖动

7. **导出大图**

### 技术架构分析

#### 核心数据结构
```python
class ImageItem:
    def __init__(self, canvas, pil_image, x=0, y=0):
        self.original_image = pil_image.convert("RGBA")
        self.scale = 1.0
        self.x = x
        self.y = y
        self.image_id = None      # Canvas 上的对象 ID
        self._tk_image = None     # Tkinter PhotoImage 对象
        self.selected = False
```

#### 交互模型
- **Canvas 坐标系统**：使用 `canvas.coords()` 和 `canvas.move()` 操作图片位置
- **碰撞检测**：`contains_point()` 方法通过矩形包含判断鼠标点击是否在图片区域内
- **Z-Order 管理**：通过 `tag_raise()` 和 `tag_lower()` 调整图层顺序
- **缩放算法**：使用 `Image.resize()` 配合 `Image.LANCZOS` 进行高质量重采样

#### 已知限制
1. **性能瓶颈**：Tkinter 的 Canvas 在处理大量高分辨率图片时会出现卡顿
2. **缩放锚点**：以鼠标为锚点的缩放实现存在微小偏移
3. **视图缩放**：没有整体视图缩放功能，只能通过滚动条查看大图
4. **状态持久化**：无自动保存，意外退出会导致数据丢失
5. **透明度**：不支持图片透明度调整

### 设计亮点
- **锚点缩放算法**：`scale_by(factor, anchor_x, anchor_y)` 方法实现了以任意点为缩放中心，这在 Tkinter 中属于高阶实现
- **多方案剪贴板读取**：同时支持 PIL 和 win32clipboard 两种方式，提高了兼容性
- **Linux 滚轮支持**：通过 `<Button-4>` 和 `<Button-5>` 事件处理了 Linux 下的滚轮事件

### 用户界面

- 底部状态栏（`ttk.Label`）

```python
def zoom_view(self, factor):
    current = self.view_scale()
    new_scale = current * factor
    if new_scale < self._min_zoom:      # 最小 5%
        factor = self._min_zoom / current
    elif new_scale > self._max_zoom:    # 最大 1000%
        factor = self._max_zoom / current
    if factor != 1.0:
        self.scale(factor, factor)
    if self._main_window:
        self._main_window.update_view_zoom_status()
```

#### 二、图片差异比对（特色功能）

##### 功能描述
自动检测两张相似图片之间的差异，并用红色半透明矩形标记差异区域。

##### 使用场景
| 场景 | 具体应用 |
|------|----------|
| **UI 测试** | 对比设计稿与实现截图，定位像素级偏差 |

| **文档校对** | 对比不同版本的流程图、架构图 |

##### 操作步骤
1. 按住 `Ctrl` 键点击选中**两张或多张**图片
2. 点击工具栏 **"比对差异"** 按钮
3. 程序自动分析并在差异区域生成红色标记框
4. 点击 **"清除标记"** 移除所有标记

##### 核心算法

**步骤一：像素级差异检测**
```python
threshold = 30  # 颜色差异阈值
block_size = 8  # 分块大小
for by in range(0, h, block_size):
    for bx in range(0, w, block_size):
        # 检查块内是否有差异像素
        if dr + dg + db > threshold:
            has_diff = True
```

**步骤二：差异块合并（连通区域分析）**
- 使用 BFS（广度优先搜索）将相邻差异块合并为连通区域
- 输出为矩形区域列表，减少标记数量，提高可读性

**步骤三：坐标映射**
- 将差异区域从像素坐标映射到场景坐标
- 考虑图片位置、缩放比例、原始尺寸

##### 技术亮点
- **分块检测**：平衡精度与性能
- **连通区域合并**：将散点差异聚合为有意义的区域
- **抗尺寸差异**：自动将对比图片缩放到基准图尺寸

#### 三、自动保存与崩溃恢复

## 技术债务与已知问题

1. **V3.0 差异比对**：仅支持 RGB 色彩空间，对于带有透明度的 PNG 图片可能检测不准确
2. **历史记录**：存储所有图片的原始副本，对于大型项目可能占用较多磁盘空间
3. **大尺寸导出**：超过 20000px 时可能内存不足，建议分批处理
4. **整体透明度**：与单张透明度的叠加关系可能造成理解困难

## 附录：常见问题（FAQ）

**问：程序无法启动，提示缺少 DLL 或 无法打开？**
答：请确保您已安装 [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist?view=msvc-170)（Windows 系统）。如果问题仍然存在，请前往 GitHub Issues 提交详细错误截图。

**问：导出的图片背景是黑色的，如何透明？**
答：导出时请选择保存格式为 **PNG**。JPEG 格式不支持透明背景，会被自动填充为白色。
