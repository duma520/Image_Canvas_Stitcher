### 第一章：初见 · 软件概览与安装

#### 1.1 这是什么软件？

**一句话概括：** 这是一个超大的、无限滚动的“数字画板”，您可以把任意图片贴上去，随便拖动、缩放、旋转，最后拼成一张完整的大图导出。

**核心概念：**
- **画布 (Canvas)：** 一个无限大的虚拟空间，就像您的桌面。
- **图片 (Image)：** 您导入或粘贴的每一张照片、截图或设计稿。
- **项目 (Project)：** 您在画布上摆放的所有图片、标记和Emoji的集合。
- **图层 (Z-Order)：** 图片在画布上的堆叠顺序，决定了谁在“上面”盖住谁。

**适合谁：**
- **设计师：** 快速收集灵感素材，进行排版尝试。
- **摄影师：** 拼接全景图、对比不同修图版本。
- **学生/教师：** 制作学习卡片、课件素材、思维导图。
- **普通用户：** 整理旅游照片、制作朋友圈拼图、截图收集。
- **程序员：** 制作UI原型、流程图、代码截图对比。

#### 1.2 如何获取与安装？

1.  **下载：** 请访问我们的GitHub项目主页：[https://github.com/duma520](https://github.com/duma520)
2.  **环境要求：** 本软件基于Python和PySide6开发，支持Windows、macOS和Linux系统。
3.  **运行：**
    - **方式一（推荐给普通用户）：** 下载我们打包好的可执行文件（.exe / .app）。直接双击运行即可。
    - **方式二（推荐给开发者）：** 如果您有Python环境，可以克隆仓库后，在终端运行 `python Image_Canvas_Stitcher.py`。
4.  **首次启动：** 启动后，您会看到一个简洁的界面，主区域是灰色的画布，顶部是工具栏。恭喜您，已经准备好了！

### 第二章：一分钟上手 · 核心工作流

让我们快速体验一下最核心的流程：**导入 -> 排列 -> 导出**。

#### 2.1 导入图片（三种方式）

| 方式 | 操作 | 适用场景 |
| :--- | :--- | :--- |
| **1. 从剪贴板粘贴** | 截图后，在软件中按 `Ctrl+V` 或点击工具栏的 **“粘贴”** 按钮。 | **最高效！** 适合从浏览器、设计软件、截图工具中快速抓取内容。 |
| **2. 拖拽文件** | 从文件夹中，直接将图片文件拖拽到软件的灰色画布区域。 | 适合批量导入本地图片。 |
| **3. 使用菜单** | 点击工具栏的 **“导入”** 按钮，在弹出的对话框中选择文件。 | 传统的文件打开方式，适合精确选择。 |

> **💡 举例：** 想象您正在写一篇报告，需要引用网页上的三张图表。您可以分别截图，然后在Stitcher中连续按三次 `Ctrl+V`，三张图就都出现在画布上了，这就是“粘贴”的威力。

#### 2.2 排列与摆放

- **移动：** 在图片上**按住鼠标左键**并拖动，即可自由移动图片位置。
- **缩放：** **选中**一张图片（点击它，周围出现蓝色边框），滚动鼠标滚轮，图片就会以鼠标位置为中心放大或缩小。
- **旋转：** 在图片上**右键点击**，在菜单中选择“旋转”子菜单，可以进行各种角度的旋转。

> **💡 举例：** 您要做一张海报。您导入了一张背景图，放在了画布中央。然后导入了一个Logo，缩小后放在了左上角。最后导入了一些文字截图，旋转了45度，斜着放在了右下角。整个过程就像在玩拼图一样直观。

#### 2.3 导出成品

当您对排版满意后：
1.  点击工具栏上的 **“导出”** 按钮。
2.  软件会自动计算所有内容的外接矩形，并加上边距。
3.  选择您想保存的格式（PNG支持透明背景，JPEG文件更小）。
4.  点击保存，一张完整的、拼接好的大图就诞生了！

### 第三章：进阶操作 · 掌握高效工具

现在您已经掌握了核心流程，让我们来看看那些能让您效率倍增的强大功能。

#### 3.1 选择与多选

- **单击选择：** 点击图片即可选中，被选中的图片会有蓝色高亮边框。
- **多选：** 按住键盘上的 `Ctrl` 键不放，然后依次点击多张图片。
- **为什么多选？** 多选后，您可以**同时移动、缩放、旋转、删除**所有选中的图片，或批量调整它们的透明度、图层顺序等。

> **💡 专业技巧：** 在画布空白处点击，可以取消所有选中。这在您需要“整体”操作时非常有用。

#### 3.2 图层管理（置顶/置底）

当图片重叠时，谁遮住了谁？
- **置顶（Bring to Front）：** 选中图片，点击工具栏的 **“置顶”** 按钮，它会出现在所有图片的最上层。
- **置底（Send to Back）：** 点击 **“置底”** 按钮，它会沉到最下层。

> **💡 举例：** 您把一张半透明的LOGO图片放在了公司照片上面，为了让LOGO更明显，您选中LOGO，点击“置顶”，它就会显示在所有元素之上。

#### 3.3 透明度调整

透明度（Opacity）是专业设计中的常用技巧。
- **单张透明度：** 选中图片，拖动工具栏上的 **“单图透明度”** 滑块。
- **整体透明度：** 不选中任何图片，拖动 **“整体透明度”** 滑块，可以像调节灯光一样，让所有图片同时变淡或变深。

> **💡 举例：** 您想对比两张设计稿的细微差别。将其中一张透明度调为50%，然后覆盖在另一张上面，通过移动位置，可以非常直观地看到哪些像素发生了变化。这正是软件内“差异比对”功能的基础。

#### 3.4 镜像翻转（水平/垂直）

- **水平翻转：** 就像照镜子，左右颠倒。
- **垂直翻转：** 上下颠倒。

您可以在选中图片后，通过工具栏按钮或右键菜单中的“镜像翻转”子菜单进行操作。

> **💡 举例：** 您导入了一张向右的箭头图片，但您的排版需要它指向左。选中它，点击“水平翻转”，箭头就指向左了，无需重新作图。

#### 3.5 视图导航（大画布漫游）

当图片很多，画布很大时，如何高效浏览？
- **平移视图：** 按住键盘上的 **空格键 (Space)**，此时鼠标会变成手掌图标，按住左键拖动即可平移整个视野。您也可以直接按下鼠标**中键（滚轮）** 并拖动来平移。
- **整体缩放视图：** 在不选中任何图片的情况下，滚动滚轮，可以缩放整个画布的视野，类似于在Photoshop中放大缩小视图。您也可以使用工具栏的 **“视图+”/“视图-”** 按钮。

> **💡 专业技巧：** 点击 **“适配”** 按钮，软件会自动缩放视野，让画布上所有图片都完整呈现在您眼前。

#### 3.6 撤回上一步 (Ctrl+Z)

操作失误了？别担心！
- **快捷键：** 按下 `Ctrl+Z`。
- **工具栏：** 点击 **“撤回”** 按钮。
- **右键菜单：** 在画布空白处右键，选择“撤回上一步”。
软件会记住您的操作步骤，支持多次撤回。

> **💡 适用范围：** 图片的移动、缩放、旋转、删除、透明度更改、图层调整、添加/删除Emoji、绘制/清除标记等几乎所有操作都可以撤回。

### 第四章：专业功能 · 释放创造力

这一章将介绍软件更独特、更强大的功能，帮助您完成专业级的工作。

#### 4.1 图片差异比对（Diff Checker）

这是一个非常有用的功能，尤其适合设计师和开发者。

**场景：** 您修改了一张图片的几个像素，但肉眼难以察觉。或者您想比较两张极其相似的截图，找出不同之处。

**操作步骤：**
1.  按住 `Ctrl` 键，点击选中**至少两张**您想比对的图片。
2.  点击工具栏上的 **“比对差异”** 按钮。
3.  软件会以您选中的**第一张图**为基准，分析后续图片的像素差异。
4.  所有存在差异的区域，都会在图片上被**红色的半透明方框**标记出来。
5.  点击 **“清标记”** 按钮可以移除所有红色标记。

> **💡 专业解释：** 软件会对图片进行逐像素比较。如果某个区域的RGB颜色值总和差异超过预设阈值（30），就会被判定为不同区域。为了更高效，它会将图片分为8x8像素的小块进行分析，而不是逐个像素，这样既能保证准确性，又能提高速度。

#### 4.2 在图片上画画做标记（Marker Tool）

您可以像在PPT上批注一样，直接在图片上画画、写字。

**如何开启：**
1.  点击工具栏的 **“标记”** 按钮，打开“标记工具”窗口。
2.  选择您需要的工具：
    - **画笔：** 自由手绘线条。
    - **直线：** 画一条笔直的线。
    - **矩形/椭圆：** 框选或圈出重点区域。
    - **箭头：** 指向关键信息。
    - **文字：** 在指定位置输入注释文字。
3.  选择颜色和画笔大小。
4.  **直接在画布上的图片上拖动鼠标**即可开始绘制。
5.  绘制完成后，标记会**自动保存**，并随图片一起移动、缩放、旋转。

> **💡 举例：**
> - **设计师：** 在客户反馈的UI设计稿上，用红色圈出需要修改的按钮，用箭头指向间距不规范的地方。
> - **教师：** 在学生的作文截图（手写体）上，用绿色标出好词好句，用红色圈出错别字。
> - **产品经理：** 在竞品分析截图上，用文字标注出功能亮点。

#### 4.3 Emoji表情系统 · 让沟通更有趣

谁说工具不能有趣？Emoji功能让您的作品和沟通更加生动。

**核心优势（v3.34+）：** Emoji会**独立保存为文件**。这意味着您关闭软件后再打开，或者加载历史项目，Emoji的位置和大小都**不会错乱**。这是永久性的修复！

**如何添加：**
1.  **快捷键：** 按下 `Win + ;` (分号) 快速调出选择器。
2.  **工具栏：** 点击 **“😀 添加表情”**。
3.  **右键菜单：** 在画布空白处或图片上右键，选择“添加Emoji”。

**两种模式：**
1.  **吸附到图片：** 选择一个Emoji，然后点击“添加到选中的图片”。这个Emoji会“粘”在图片上，移动图片时，它会跟着一起走。
2.  **独立添加到画布：** 选择一个Emoji，点击“添加到画布”。它可以自由放置在画布的任何位置，不依附于任何图片。

**操作Emoji：**
- 选中它，滚动滚轮可以调整大小。
- 右键点击它，可以进行删除、放大、缩小、分离/吸附等管理操作。

> **💡 举例：**
> - **UI/UX设计师：** 在界面原型图上，用“👍”或“👎”表情快速表示对设计方向的认同或反对。
> - **教师：** 在学生作业图片上，添加“⭐”或“❤️”表情作为鼓励。
> - **普通用户：** 在朋友的照片上，用“🎉”或“🥳”表情来表达祝福。

#### 4.4 历史记录与项目管理

如果您需要保存多个版本的排版方案，或者想随时回到之前的某个状态，这个功能是您的得力助手。

**保存历史：**
1.  排版完成后，点击工具栏的 **“存历史”**。
2.  给这个版本起个名字（或使用默认时间戳）。
3.  软件会保存当前所有图片、标记和Emoji的状态。

**管理历史：**
1.  点击工具栏的 **“历史”** 按钮。
2.  在对话框中，您可以看到所有保存的版本列表，并预览其缩略图。
3.  您可以 **“加载编辑”** 来恢复某个版本，或 **“删除”** 不再需要的版本。

> **💡 专业场景：** 您为同一个项目设计了三个不同的排版方案（方案A、B、C）。您可以将它们分别保存为三个历史记录。然后您可以随时加载方案A给客户看，看完后再加载方案B继续修改，完全不用担心会弄乱。

#### 4.5 自定义背景

您可以根据需要，更换画布的背景，让工作环境更舒适，或辅助您进行对齐。

在 **“设置”** 对话框中，您可以：
- **纯色：** 选择任意颜色作为背景。
- **形状：** 在背景上绘制多达40多种形状（如网格、圆点、三角、六边形、心形等），形成有规律的底纹，帮助对齐和构图。
- **图案：** 预设了20多种复杂图案（如棋盘格、人字形、迷宫、马赛克等），满足更专业的视觉需求。
- **自定义图片：** 将一张图片设置为背景。

> **💡 特别提醒：** 在“设置”中开启 **“整体缩放时背景显示缩放效果”** 后，当您用 `Ctrl+滚轮` 缩放视图时，背景图案（如网格）会一起变大变小。关闭此功能，背景图案则固定不动。这可以根据您的个人习惯和对齐需求来灵活调整。

### 第五章：高级篇 · 定制与优化

#### 5.1 自定义工具栏

您可以让工具栏只显示您最常用的功能，界面更加清爽。

1.  点击 **“设置”** 按钮。
2.  切换到 **“工具栏”** 标签页。
3.  点击 **“打开工具栏自定义...”**。
4.  在弹出的窗口中，您可以勾选或取消勾选任何功能按钮。
5.  点击“应用”或“确定”即可生效。

#### 5.2 性能模式

如果您处理的是大量高分辨率图片，可能会感到卡顿。

- 在 **“设置”** -> **“性能”** 标签页中，您可以选择：
    - **高质量：** 画面最精细，但可能稍慢。
    - **平衡（推荐）：** 性能与画质的良好折中。
    - **高性能：** 优先保证流畅的操作体验，适合处理大量图片。
- 您也可以单独关闭 **“抗锯齿”** 或 **“平滑图片缩放”** 来进一步提升性能。

### 第七章：常见问题 (FAQ)

**1. 问：软件是免费的吗？**
答：是的，本项目基于MIT开源许可证，完全免费使用。

**2. 问：支持哪些图片格式？**
答：支持所有常见的图片格式，包括 PNG, JPG, JPEG, BMP, GIF, WEBP, TIFF 等。

**3. 问：导出的图片质量会下降吗？**
答：导出时，您可以控制质量。对于PNG格式，它是无损的。对于JPEG，您可以在保存时选择高质量（如95%），几乎看不出画质损失。

**4. 问：自动保存的文件在哪里？**
答：它们位于软件目录下的 `autosave` 文件夹内。如果您想彻底清空自动保存，可以删除该文件夹内的内容。

**5. 问：我可以把图片从画布上移出视线范围吗？**
答：当然可以，您可以直接把图片拖拽到画布的边缘之外。由于画布理论上是无限的，所以图片不会“丢失”，您可以通过缩小视图来找到它。
