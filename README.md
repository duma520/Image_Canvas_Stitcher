## 1. 引言

**Image Canvas Stitcher**（图片自由拼接工具）是一款轻量级、跨平台的桌面应用程序，专为需要快速组合、比对、排版多张图片的用户设计。无论您是设计师、摄影师、前端开发人员、测试工程师、教育工作者，还是普通办公人员，都可以用它来：

- 将多张截图、照片或设计稿自由拖放到无限画布上，任意调整位置和大小。
- 通过透明度叠加和差异比对功能，快速发现两个版本之间的视觉差异（非常适合 UI 回归测试）。
- 保存工作进度，历史记录让您随时回到之前的状态。
- 一键导出拼接后的完整大图，用于演示、文档或打印。

**设计理念**：  
- **零门槛**：无需任何专业软件基础，打开即用，所有操作都有直观的按钮和快捷键。  
- **高自由度**：无限大的虚拟画布，图片可随意拖动、缩放、层叠。  
- **专业功能**：差异比对、透明度控制、历史快照，满足 QA 和设计师的精细需求。  
- **完全开源**：基于 PySide6 (Qt for Python)，遵循 MIT 许可证，您可自由修改、分发。

## 2. 安装与运行

### 2.1 环境要求
- **操作系统**：Windows 7+ / macOS 10.15+ / Linux (支持 X11/Wayland)
- **Python 版本**：3.8 或更高（推荐 3.10+）
- **依赖库**：PySide6（Qt 的 Python 绑定）

### 2.2 安装步骤

#### 方法一：直接运行已编译的可执行文件（推荐非编程用户）
- 访问项目 Releases 页面（GitHub），下载对应平台的 `.exe`（Windows）或 `.app`（macOS）或 `.AppImage`（Linux）。
- 双击运行，无需安装 Python。

#### 方法二：从源码运行（适合开发者或喜欢命令行）
1. 克隆仓库或下载源码包：
   ```bash
   git clone https://github.com/duma520/ImageCanvasStitcher.git
   cd ImageCanvasStitcher
   ```
2. 创建虚拟环境（可选但推荐）：
   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux/macOS
   venv\Scripts\activate         # Windows
   ```
3. 安装依赖：
   ```bash
   pip install PySide6
   ```
4. 运行主程序：
   ```bash
   python Image_Canvas_Stitcher.py
   ```
   如果文件名不同，请使用最新的 `Image_Canvas_Stitcher - 3.3 +class ProjectInfo.py`。

### 2.3 首次启动
- 程序会自动在 **程序所在目录** 下创建 `autosave` 和 `history` 文件夹，用于存储自动保存和历史快照。
- 如果之前有关闭未保存的画布，下次启动时会自动恢复。

## 3. 快速入门（5 分钟上手）

假设您想将两张截图拼接在一起并导出：

1. **启动程序** → 出现一个深灰色的大画布。
2. **粘贴图片**：先复制一张图片（截图软件或按 `Ctrl+C`），然后在程序中按 `Ctrl+V`，图片会出现在画布中央。
3. **再粘贴第二张**：重复上一步，第二张图会错位一点放置，避免完全重叠。
4. **拖动调整**：鼠标左键按住任意一张图片拖动，将它们并排放置。
5. **缩放图片**：单击选中一张图片（出现蓝色边框），滚动鼠标滚轮可以放大/缩小这张图；按住 `Ctrl` 同时滚动滚轮可以缩放整个视图（方便预览全貌）。
6. **导出拼接**：点击工具栏的“导出大图”按钮，选择保存位置和格式（推荐 PNG 保持透明背景），即可得到一张包含所有图片的完整大图。

**恭喜您！** 您已经完成了第一个拼接作品。

## 5. 核心功能使用指南

### 5.1 导入图片

**多种方式**，适应不同工作流：

- **从文件导入**：点击“导入图片”按钮，或使用 `Ctrl+O`（未绑定，但可通过菜单），选择常见格式（PNG, JPG, BMP, GIF, WebP, TIFF 等）。
- **拖拽文件**：直接从文件管理器中将图片拖拽到画布上，会出现在鼠标落点位置。
- **从剪贴板粘贴**：最常用的方式！复制任意图片（截图、网页图片、画图工具内容），在程序中按 `Ctrl+V` 或点击“粘贴”按钮，图片即粘贴到画布中央（略微偏移以避免完全覆盖）。

**专业技巧**：
- 您可以在粘贴前先调整好视图缩放，让图片以合适大小出现。
- 支持一次粘贴多张图片吗？可以连续按 `Ctrl+V` 多次，每次都会新增一张。

### 5.2 选择与移动图片

- **单击选择**：点击任意图片，它会显示蓝色边框，表示被选中。
- **框选多张**：在画布空白处按住左键拖动，会出现虚线框，松开后框内的所有图片都被选中。
- **追加选择**：按住 `Ctrl` 键不放，再单击其他图片，可以将其加入当前选择（或取消已选）。
- **移动图片**：选中后，用鼠标左键按住图片任意位置拖动，即可自由移动。多选时，拖动任意一张，所有选中的图片会一起移动（相对位置不变）。
- **精准定位**：状态栏会实时显示选中图片的左上角坐标（单位：像素），便于对齐。

**举例**：  
假设您有三张截图，需要按从左到右的顺序排列。您可以：
1. 框选三张图片。
2. 拖动它们使整体靠左。
3. 取消框选，逐张微调位置，参考状态栏坐标保证间距一致。

### 5.3 缩放图片与视图

**缩放图片**（改变图片的显示大小，不修改原始图像）：
- 选中图片后，滚动鼠标滚轮，图片会以鼠标指针为锚点放大或缩小。
- 或者使用工具栏的“图片放大 +” / “图片缩小 -” 按钮（每次 20% 步进）。
- 点击“图片重置”恢复为原始大小（100%）。

**缩放整个视图**（相当于放大镜，不影响图片数据）：
- 按住 `Ctrl` 键同时滚动滚轮，视图会以鼠标指针为中心缩放。
- 工具栏的“视图放大/缩小”按钮提供相同功能。
- “视图100%”重置为原始比例；“适配全部”自动调整视图让所有图片可见。

**典型场景**：  
- 当您需要精细调整一张图片的细节时，先放大视图（Ctrl+滚轮），然后选中该图片，用滚轮微调其大小。
- 要查看整体布局时，点击“适配全部”快速回到全貌。

### 5.4 调整图层顺序（置顶/置底）

图片在画布上是分层叠加的，后导入的图片默认在上层。若想改变覆盖关系：
- 选中一张或多张图片。
- 点击“置顶”将其移到最上层（覆盖其他图片）。
- 点击“置底”将其移到最下层（被其他图片覆盖）。
- 若有多张选中，它们会保持相对顺序整体移动。

**使用场景**：制作拼贴画时，背景图应置底，装饰元素置顶。

### 5.5 透明度调整（单张与整体）

- **单张透明度**：选中图片后，拖动工具栏的“单图透明”滑块（0~100%），该图片的透明度实时变化。0% 完全透明（不可见），100% 完全不透明。也可通过右键菜单快速设为 10%/25%/50%/75%/100%。
- **整体透明度**：拖动“整体透明”滑块，所有图片同时调整透明度（相当于全局混合比例）。例如，整体设为 50% 后，每张图片的实际透明度 = 自身透明度 × 50%。这常用于快速预览半透明叠加效果。

**举例**：  
设计 logo 叠加时，将底图保持 100%，上层 logo 设为 50% 半透明，整体透明保持 100%，即可看到 logo 透出底图。

### 5.6 差异比对（视觉回归测试）

这是面向测试人员、设计师的**杀手级功能**。当您有两张高度相似的图片（例如同一 UI 界面不同版本），需要找出细微差异时：

1. 在画布上同时导入两张图片（建议放在相近位置）。
2. 按住 `Ctrl` 单击两张图片，将它们都选中（或框选）。
3. 点击“比对差异”按钮。
4. 程序会以**第一张选中图**为基准，逐像素比较其他图片（缩放至相同尺寸），颜色差异超过阈值（默认 30 灰度差）的区域会被标记为**红色半透明矩形**。

**解读结果**：
- 红色标记覆盖的区域即差异区域，您可以直接在画布上目视检查。
- 如果无差异，会弹窗提示“未检测到明显差异”。
- 点击“清除标记”移除所有红色框。

**高级用法**：  
- 支持同时比对多张图片（例如 A vs B, A vs C），结果会分别标记在 B 和 C 上。
- 您可以调整比对算法（代码中 `threshold` 变量，默认 30），自行修改后重新运行。

**适用人群**：UI 自动化测试工程师、设计师核对设计稿与实现、文档版本对比等。

### 5.7 自动保存与崩溃恢复

- 程序会**自动**在每次操作后（移动、缩放、透明度变化等）延迟 1.5 秒保存当前画布状态到 `autosave` 文件夹。
- 如果程序意外崩溃或正常关闭，下次启动时会自动恢复上次保存的画面，并在状态栏提示“已自动恢复上次画面，共 X 张图片”。
- **手动保存**：您无需手动操作，所有修改都会被自动保存。关闭前程序也会执行一次保存。

**存储位置**：  
`程序目录/autosave/` 下包含 `state.json`（描述图片位置、缩放、透明度等）和 `images/` 文件夹（缓存的原图）。您可以手动删除这些文件来清除自动保存。

### 5.8 历史记录管理（快照与回滚）

与自动保存不同，历史记录是**用户主动保存**的“里程碑”，可以长期保留。

- **保存快照**：点击“保存到历史”，为当前画布状态命名（默认使用时间戳）。快照会保存所有图片的原始图像、位置、缩放、透明度和图层顺序，并生成一张缩略图。
- **查看历史**：点击“历史记录”打开对话框，左侧列表显示所有快照（按时间倒序），右侧预览缩略图和信息（图片数量）。
- **加载快照**：选择一条记录，点击“加载编辑”，当前画布会被清空并恢复为该快照的内容（同时自动保存此次加载）。
- **删除快照**：在历史记录对话框中选中并点击“删除”。

**限制**：最多保存 50 条历史记录（可修改 `MAX_HISTORY_ITEMS` 常量）。

**典型用例**：  
- 在拼接过程中想尝试不同布局，先保存当前状态，然后大胆调整，不满意即可回退。
- 项目阶段性成果存档。

### 5.9 导出拼接大图

将画布上所有图片合成为一张完整图片：

1. 点击“导出大图”。
2. 程序自动计算所有图片的外接矩形，并向外扩展 20 像素边距。
3. 若尺寸过大（超过 20000×20000），会弹出警告确认。
4. 选择保存路径和格式（PNG 支持透明，JPG 会填充白色背景，BMP 无压缩）。
5. 导出完成后显示尺寸和路径。

**导出顺序**：按图层从下到上绘制，因此置顶的图片会覆盖置底的图片。

**常见问题**：
- 导出的图片空白？检查是否所有图片都可见（透明度不为 0%）。
- 图片模糊？导出时使用原始缩放分辨率，如果图片被缩小，导出时会保持缩放后的像素；若要高清导出，请先将图片缩放回较大尺寸再导出。

### 5.10 清空画布

一键删除所有图片（包括差异标记）。点击后弹出确认对话框，防止误操作。

## 6. 高级应用与技巧

### 6.1 大画布平移

当图片超出视口时，您需要平移画布：
- **临时平移**：按住 `空格键` 不放，然后按住鼠标左键拖动（光标变为手型），即可平移视图。
- **中键平移**：直接按住鼠标中键（滚轮键）拖动。
- **滚轮平移**：没有选中的图片时，直接滚动滚轮默认上下滚动；按住 `Shift`+滚轮可左右滚动（未实现，但可通过滚动条）。

**专业技巧**：结合“适配全部”快速回到全貌，再放大局部进行细调。

### 6.2 键盘快捷键大全

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+V` | 粘贴图片 |
| `Delete` / `Backspace` | 删除选中的图片 |
| `Ctrl+A` | 全选所有图片 |
| `Ctrl+0` | 重置视图缩放为 100% |
| `Ctrl+=`（等号） | 视图放大 20% |
| `Ctrl+-`（减号） | 视图缩小 20% |
| `Space`（按住）+ 左键拖动 | 平移视图（手型工具） |
| 鼠标滚轮 | 缩放选中的图片（有选中时）；无选中时上下滚动 |
| `Ctrl`+滚轮 | 缩放整个视图 |
| 右键单击 | 弹出上下文菜单（功能丰富） |

### 6.3 右键菜单详解

**选中图片时右键**：
- 删除
- 放大 / 缩小 / 重置大小
- 透明度子菜单（100%, 75%, 50%, 25%, 10%）
- 置顶 / 置底

**空白处右键**：
- 视图放大 / 缩小 / 重置 / 适配全部
- 清除差异标记
- 粘贴图片

**专业提示**：右键菜单是最快捷的操作方式，建议多用。

### 6.4 处理大量图片的性能优化建议

程序使用 Qt 的 Graphics View 框架，默认已开启 `SmoothPixmapTransform` 和 `DeviceCoordinateCache`（在 v3.1 中优化）。若您需要处理上百张图片：
- 尽量使用 PNG 等轻量格式，避免超大 TIFF。
- 当图片数量很多时，可适当降低“整体透明度”滑块的操作频率。
- 如果感觉卡顿，可以关闭抗锯齿（修改源码中的 `setRenderHints`），但会影响视觉质量。
- 程序自动保存采用防抖延迟 1.5 秒，减少频繁 I/O。

### 6.5 自定义界面（背景色、缩放范围）

- **更改画布背景色**：在 `ImageCanvasView.__init__` 中修改 `setBackgroundBrush(QBrush(QColor(43, 43, 43)))` 的 RGB 值。
- **缩放范围限制**：修改 `_min_zoom` 和 `_max_zoom`（默认 0.05 ~ 10.0）。
- **项目信息**：所有元数据集中在 `ProjectInfo` 类中，可修改作者、版本、标题格式等。

## 7. 常见问题解答（FAQ）

**Q1：为什么粘贴图片没反应？**  
A：请确保剪贴板中有图片（例如使用截图工具截取后复制）。如果是从文件复制，请使用“导入图片”而非粘贴。

**Q2：导出的图片透明背景变黑？**  
A：如果您保存为 JPEG 格式，程序会自动填充白色背景。若保存为 PNG 则保留透明。如果 PNG 导出后背景变黑，请检查图片本身是否带有透明度。

**Q3：差异比对显示很多红色块，但肉眼看上去一样？**  
A：阈值（30）可能过低，导致细微的颜色差异（如抗锯齿）被标记。您可以调高阈值，或接受这些标记作为参考。

**Q4：历史记录保存在哪里？可以备份吗？**  
A：历史记录位于 `程序目录/history/` 下，每个快照为一个子文件夹。您可以复制整个 `history` 文件夹进行备份。

**Q5：自动保存和手动保存有什么区别？**  
A：自动保存是实时备份当前工作，用于恢复；手动保存是用户主动创建的历史快照，用于长期版本管理。

**Q6：能导入 PDF 或 SVG 吗？**  
A：目前仅支持常见的栅格图像格式（PNG, JPG, BMP, GIF, WebP, TIFF）。若需导入矢量图，请先转换为 PNG。

**Q7：如何联系作者？**  
A：我们不提供私人邮箱，所有问题请在 GitHub Issues 上公开提出，以便其他用户也能参与讨论和受益。

## 8. 版本更新记录

本工具经历了多个迭代，从最初的 Tkinter 版本到如今基于 PySide6 的功能丰富的 3.3 版本。以下是主要里程碑：

### v1.0（Tkinter 原型）
- 基于 Tkinter + Pillow，支持基本拼接、拖拽（需额外库）、粘贴和导出。
- 无视图缩放、无透明度、无历史记录。

### v2.0（PySide6 重构）
- 完全重写为 PySide6，提升性能和跨平台兼容性。
- 支持无限画布、更流畅的交互。
- 引入图层顺序（置顶/置底）。

### v2.1（图标支持）
- 添加窗口图标（icon.ico），美化界面。

### v2.2（整体视图缩放）
- 新增视图缩放功能（Ctrl+滚轮），适配全部，状态栏显示缩放比例。
- 空白处右键菜单增加视图操作。

### v3.0（重大功能更新）
- **透明度**：单张和整体透明度滑块。
- **差异比对**：像素级对比，红色标记差异。
- **自动保存**：防抖保存，崩溃恢复。
- **历史记录**：快照管理，预览和加载。

### v3.1（性能与交互优化）
- 使用 BSP 树索引和 DeviceCoordinateCache 大幅提升大量图片时的渲染性能。
- 支持框选多图（橡皮筋选择），多选后批量操作。
- 丰富右键菜单：透明子菜单、全选、取消全选、保存历史等。

### v3.2（数据目录调整）
- 自动保存和历史记录从用户目录移至程序所在目录，便于便携式使用（U 盘）。
- 增加导出文件名时间戳。

### v3.3（项目信息集中管理）
- 新增 `ProjectInfo` 类，集中管理程序名称、版本、作者、版权、主页等信息。
- 窗口标题和状态栏提示统一使用该类，便于后期定制。
- 优化了部分代码结构，提升可维护性。

**v3.3 vs v3.2 主要区别**：
- 界面标题由硬编码改为动态获取，且支持未来扩展（如显示用户名）。
- 状态栏提示调用 `ProjectInfo.get_status_tip()`，便于多语言或主题修改。
- 导出默认文件名使用 `ProjectInfo.get_export_default_filename()`，自动包含时间戳。
- 内部元数据更加清晰，为后续打包发布做准备。
