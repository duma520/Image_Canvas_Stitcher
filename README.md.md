# 图片自由拼接工具 - Image Canvas Stitcher

一个轻量级的 Python 桌面工具，专门用来**自由摆放多张图片**，就像在桌面上拼地图一样。非常适合拼接游戏截图、漫画分镜、参考图对比等场景。

## ✨ 功能特点

- 📋 **剪贴板粘贴**：按 `Ctrl+V` 直接粘贴截图，不用保存文件
- 🖱️ **自由拖动**：鼠标左键按住图片随便挪位置
- 🔍 **滚轮缩放**：选中图片后滚轮放大缩小（以鼠标位置为中心）
- 🗺️ **大画布平移**：按住 `空格` + 左键拖动，或鼠标中键拖动来移动视图
- 📁 **拖拽导入**：直接把图片文件拖进窗口
- 📤 **导出大图**：把摆好的所有图片导出成一张完整的 PNG/JPG
- 🔢 **图层管理**：置顶 / 置底，调整图片叠放顺序
- 🎯 **右键菜单**：删除、缩放、图层调整一键操作

## 🚀 快速使用

### 方法一：直接运行 Python 脚本

```bash
# 安装依赖
pip install PySide6

# 运行
python image_canvas_stitcher.py
```

### 方法二：打包成 EXE（推荐）

双击运行 `build_exe.bat`，等待 2-5 分钟，生成的 `图片拼接工具.exe` 在 `dist` 文件夹里。

## 🎮 操作指南

| 操作 | 功能 |
|------|------|
| `Ctrl + V` | 从剪贴板粘贴图片 |
| 左键按住拖动 | 移动选中的图片 |
| 滚轮 | 缩放选中的图片（以鼠标为中心） |
| `空格` + 左键拖动 | 平移整个画布视图 |
| 鼠标中键拖动 | 平移整个画布视图 |
| `Delete` | 删除选中的图片 |
| 右键图片 | 打开菜单（删除/缩放/图层） |
| 点击空白处 | 取消选中 |

## 💡 使用场景

- **游戏地图拼接**：截好几张游戏地图，拼出完整大地图
- **漫画/长图拼接**：把多页漫画自由排列
- **参考图整理**：摆一堆参考图对比着看
- **拼图复原**：把打散的图片碎片拼回去
- **UI 设计稿对比**：多个版本摆在一起对比

## 📦 导出说明

点击「导出大图」按钮，会自动计算所有图片的边界，生成一张包含全部内容的完整图片。
- PNG 格式支持透明背景
- JPG 格式自动填充白色背景
- 最大支持 20000×20000 像素（超过会提示确认）

## 🔧 技术说明

- **GUI 框架**：PySide6 (Qt 6) - 原生 Graphics View 框架，流畅的图形画布操作
- **图像处理**：Qt 内置 QImage / QPixmap
- **拖放支持**：Qt 原生支持，无需额外库
- **打包工具**：PyInstaller
- **兼容系统**：Windows 10/11（推荐）、Linux、macOS

## 📝 已知问题

- 特别大的图片（单张超过 4K）缩放时可能略有卡顿，属于正常现象
- 部分截图工具复制的图片格式特殊，如果粘贴失败，建议先保存为文件再导入
